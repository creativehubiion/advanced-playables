iion · advanced playables

R&D creatives for sensor-driven HTML5 playable ads.

  • tilt-racer
    Playable demo — tilt phone to steer a car, dodge oncoming traffic, collect coins. 25-second loop. Drag-to-steer fallback when gyro is denied or silently blocked. Vector graphics, synthesised audio, fully single-file.
  • sensor-probe-telemetry
    Real-traffic sensor probe — fires discrete events to iion's staging DMP so we learn which sensor APIs work in real publisher SDK WebViews. GAM and PLL flavours. Designed to be uploaded as a creative and run as a small test campaign.
  • sensor-probe
    Diagnostic creative — surfaces MRAID state, Permissions Policy, DeviceMotion / DeviceOrientation firing, mic / cam / geo permission state, frame rate, GAM macro substitution. Drop into any ad slot to learn what the rendering WebView allows.
